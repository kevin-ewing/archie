# Story-writing course library

Ten course folders keyed to the original shortlist. Each folder records its provider, focus, access status and local materials when present. Retrieved 17 November 2026.

Start with each folder’s README. MIT’s modern packages open from `materials/index.html` and have original files under `materials/static_resources/`. Yale’s `transcripts/` contains plain text for quick search. Course recordings, rights-restricted readings, and Sanderson’s notes can be opened from the provider links.

For Archie, look in **01** for branching narrative, **02–05** for scenes and character arcs, **06–07** for letters and personal history, and **08–10** for medium, form and player choices.
